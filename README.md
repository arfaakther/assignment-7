# 🛒 বাজার দর | BazarDor

**প্রয়োজনীয় পণ্যের দাম এক নজরে।**

BazarDor is a Bengali market-price tracking web application that helps users explore the prices of everyday essentials in Bangladesh. Users can compare prices across markets, track price changes, browse product categories, and make informed shopping decisions.

🌐 **Live Website:** [https://bazar-dor-chi-teal.vercel.app/](https://bazar-dor-chi-teal.vercel.app/)

## ✨ Key Features

1. **📊 Today's Market Prices**  
   Explore the latest available prices of essential products, including rice, vegetables, fish, meat, and other everyday items.

2. **📈 Price Change Tracking**  
   View price increases and decreases with percentage indicators to understand how product prices change compared with previous periods.

3. **🗂️ Product Categories & Sorting**  
   Browse products by category and sort prices from low to high or high to low for easier comparison.

4. **🏪 Market-Wise Price Comparison**  
   View minimum, maximum, and average prices, along with market-specific price information, to help compare costs.

5. **🔐 User Authentication**  
   Sign up and sign in using email and password, with supported social authentication options for convenient account access.

## 🛠️ Technologies Used

- **Next.js** — React framework with App Router
- **React** — Component-based user interface
- **TypeScript** — Type-safe development
- **Tailwind CSS** — Responsive styling
- **daisyUI** — Reusable UI components and styling utilities
- **Better Auth** — Authentication and session management
- **MongoDB** — Database for authentication-related data
- **react-hot-toast** — Toast notifications
- **Vercel** — Deployment and hosting



## 📱 Responsive Design

BazarDor is designed to provide a convenient browsing experience across mobile phones, tablets, and desktop devices.
